# 🕯️ טיימר סוכרת ליום כיפור וניטור סוכר רציף LibreLinkUp

[**English**](README.md) | [**עברית**](README.he.md) | [**מדריך תרגום (Translation Guide)**](TRANSLATION_GUIDE.md)

מערכת אוטומטית עצמאית לניהול **טיימר אכילה ושתייה לשיעורים** ותצוגת **מד סוכר רציף (CGM)**, המיועדת במיוחד לחולי סוכרת ולאנשים בעלי צרכים רפואיים הנדרשים לאכול או לשתות ב**יום הכיפורים** (*פיקוח נפש*) ללא מגע במכשירים אלקטרוניים במהלך הצום.

> [!WARNING]
> ### ⚠️ הבהרה רפואית והלכתית חשובה
> **יש להיוועץ ברופא המטפל וברב פוסק הלכה מוסמך לפני השימוש ביישום זה.**
>
> - **הנחיה רפואית**: ניהול סוכרת או כל מצב רפואי אחר ביום הכיפורים כרוך בסיכון בריאותי משמעותי (*פיקוח נפש*). חובה להיוועץ בצוות הרפואי המטפל לקבלת הנחיות מפורטות לגבי צום, מרווחי אכילה ושתייה, יעדי סוכר והתאמת מינוני תרופות או אינסולין.
> - **הנחיה הלכתית**: מידות האכילה והשתייה (*שיעורים*) ומרווחי הזמן הנדרשים חייבים להיקבע מראש מול רב אורתודוקסי מוסמך.
> - **הסרת אחריות**: תוכנה זו ניתנת לשימוש כמות שהיא ("AS IS") למטרות מידע ונוחות בלבד. המחברים והתורמים **אינם נושאים באחריות כלשהי** לכל תקלה, שגיאה בתוכנה, אי-דיוק בנתונים, או סיבוך רפואי וחירום בריאותי העלולים לנבוע מהשימוש ביישום. השימוש בתוכנה הינו באחריות המשתמש הבלעדית.

## 🌟 רקע ומטרת המערכת

על פי ההלכה, אדם שמצבו הבריאותי מחייב אכילה או שתייה ביום הכיפורים מונחה לצרוך כמויות מדודות קטנות (*שיעורים* — לרוב פחות מכ-30–45 סמ"ק מזון / פחות מכ-40 סמ"ק נוזלים) במרווחי זמן קבועים (בדרך כלל כל 9, 8, 6 או 4 דקות, לפי הכרעת הרופא והרב).

הפעלת טלפונים, לחיצה על כפתורים או מגע במכשירים אלקטרוניים אסורים ביום הכיפורים. מערכת זו תוכננה כך ש**מגדירים אותה פעם אחת בערב יום כיפור**, מפעילים אותה ב**מצב מסך מלא**, והיא ממשיכה לפעול ברציפות ובאופן אוטונומי לחלוטין במשך יותר מ-25 שעות ללא צורך במגע כלשהו.

## ✨ תכונות עיקריות

### 1. ⏱️ טיימר אכילה במרווחים דו-ערוצי ($T$ ו-$T/2$)
- **מרווח ראשי ($T$)**: ספירה לאחור חזותית וצלצול הרמוני המציין מתי הגיע הזמן לצרוך את השיעור הבא (למשל: 9:00, 8:00, 6:00, 4:00, או כל מרווח מותאם אישית).
- **ערוץ הכנה לחצי הדרך ($T/2$)**: משמיע צליל עדין ומובחן במחצית המרווח (למשל בדקה 4:30 במרווח של 9:00 דקות), כדי לתת התראה מוקדמת ורגועה להכין את המים או המזון ללא לחץ.
- **טבעת התקדמות ניאון**: אנימציית SVG עגולה ומוארת המאפשרת לראות את מצב הטיימר מכל מקום בחדר.
- **כפתורי קיצור מהירים לשיעורים הלכתיים**: כפתורי בחירה מהירה של 9 דק', 8 דק', 6 דק', 5 דק' ו-4 דק'.

### 2. 🩸 חיבור למד סוכר רציף LibreLinkUp וגרף מגמות חי
- **סנכרון ענן בזמן אמת**: מתחבר ישירות ובאופן מאובטח ל-API הרשמי של **LibreLinkUp** (חיישני FreeStyle Libre 2 ו-Libre 3 של חברת אבוט) לניטור רציף של רמות הגלוקוז.
- **תמיכה בכל אזורי השרת בעולם**: תמיכה מלאה בשרתי ארה"ב (US), אירופה (EU), גלובלי (Global), גרמניה, צרפת, יפן, אסיה-פסיפיק, קנדה ואיחוד האמירויות.
- **כרטיסי תצוגה ברורים**: ערך סוכר נוכחי (מ"ג/ד"ל), חצי מגמה (↑, ↗, →, ↘, ↓), וזמן שעבר מהקריאה האחרונה.
- **גרף היסטוריית סוכר ל-12 שעות**: חלוקה לאזורי יעד צבעוניים (היפוגליקמיה <70 באדום, טווח יעד בירוק, היפרגליקמיה >180 בצהוב).
- **מצב הדמיה (דמו) מובנה**: מאפשר לבדוק את התנהגות המערכת וההתראות (סוכר נמוך 58, תקין 110, גבוה 225) בערב יום כיפור ללא צורך באינטרנט.

### 3. 🔔 צלצולים הרמוניים עדינים והשתקה אוטומטית
- **מנוע סאונד מובנה (Web Audio)**: ללא תלות בקבצי שמע חיצוניים. הצלילים נוצרים בזמן אמת באמצעות מתנדים הרמוניים עדינים:
  - 🧘 **קערה טיבטית / זן** (צליל עמוק, מהדהד ומתאים לשינה)
  - 🪵 **מרימבה מעץ** (צליל עץ חם ורך)
  - 🎐 **פעמון רוח** (צליל צלול ועדין)
  - 💧 **טיפת מים מרגיעה** (צליל אורגני ושקט)
  - ✈️ **צלצול תא נוסעים** (דינג-דונג קלאסי עדין)
- **השתקה אוטומטית מלאה**: הצלצולים וההתראות דועכים ונפסקים אוטומטית לאחר 3–5 שניות, כך שאין צורך לגעת במכשיר כדי להשתיקם.
- **הגבלת הקראת קולית**: הקראה קולית מופעלת אך ורק בעת התראות סוכר חריגות (ולא בצלצולי הטיימר השגרתיים).

### 4. 🕯️ שעון ספירה לאחור למוצאי יום כיפור (זמני הלכה)
- **חישוב זמנים הלכתי מדויק**: מבוסס על ספריית `kosher-zmanim` לחישוב זמני שקיעה, צאת הכוכבים וסיום הצום לכל מיקום בעולם.
- **התאמה למנהגים וחומרות**: תמיכה בתוספת דקות (חומרא: +0, +18, +30, ושיטת רבנו תם 72 דק') או הזנה ידנית מלאה של שעת סיום הצום.
- **תזכורת לבדיקת לוח בית הכנסת**: המערכת מזכירה לוודא את השעה המחושבת מול לוח השנה הרשמי של בית הכנסת או מרא דאתרא.

### 5. 🛡️ מגן נעילת מסך ומקלדת (חסין חתולים ולחיצות אקראיות)
- **לכידת מקלדת הרמטית**: חוסם לחלוטין לחיצות מקלדת (מקש רווח, מקשי פונקציות, מספרים, ולחיצות אקראיות של חתול הדורך על המקלדת).
- **חסימת גלילה ומחוות מגע**: נועל גלילת עכבר ומחוות מסך מגע כדי שהתצוגה לא תזוז ממקומה.
- **חסימת תפריטי עכבר וסימון טקסט**: מונע גרירה אקראית של טקסט ותפריטי קליק-ימני.
- **חלונית שחרור נעילה עם קוד PIN**:
  - מקלדת מגע נוחה על המסך להזנת קוד השחרור.
  - מציג את קוד השחרור בחלונית עצמה (**"קוד ה-PIN שלך: 1234"**) כדי למנוע נעילה בשגגה, תוך חסימת חיות מחמד משינוי הגדרות.
  - נסגר ומתאפס אוטומטית לאחר 60 שניות ללא מגע.

### 6. ☀️ מניעת כיבוי מסך ל-25+ שעות (Wake Lock)
- **חסימת מצב שינה ברמת מערכת ההפעלה**: בגרסת Electron נעשה שימוש ב-`powerSaveBlocker.start('prevent-display-sleep')` המונע עמעום מסך, כיבוי צג או הפעלת שומר מסך.
- **תמיכה ב-Screen Wake Lock API**: גיבוי אוטומטי גם בעבודה דרך דפדפן רגיל עם חיווי מואר בסרגל העליון.

### 7. 🌐 תמיכה מלאה בריבוי שפות (i18n)
- תמיכה מלאה בעברית ובאנגלית עם יישור ימין-שמאל (RTL/LTR).
- כל מחרוזות הממשק וכל הודעות השרת (כולל שגיאות התחברות ופיענוח דיאגנוסטי) מנוהלות בקובצי JSON נפרדים.
- ברירת המחדל הינה אנגלית (`en`), וניתן לעבור לעברית בלחיצת כפתור אחת.

## 🚀 התקנה והפעלה מהירה

### דרישות מוקדמות
- [Node.js](https://nodejs.org/) (גרסה 18 ומעלה)
- `npm` (מגיע מותקן עם Node.js)

### 1. הורדת הקוד והתקנת תלויות
```bash
git clone https://github.com/binyaminyblatt/yom-kippur-diabetes-timer.git
cd yom-kippur-diabetes-timer
npm install
```

### 2. הפעלת היישום

#### אפשרות א': יישום שולחני מלא עם Electron (מומלץ)
```bash
npm run dev
```
*מפעיל את השרת המקומי ופותח את היישום השולחני במצב מסך מלא.*

#### אפשרות ב': הפעלת שרת אינטרנט בלבד (לגישה מדפדפן)
```bash
npm start
```
*פתחו את הדפדפן וגשו לכתובת `http://localhost:3000`.*

### 2. 🔒 תמיכה אוטומטית מלאה בסינון SSL ותעודות אבטחה של מערכת ההפעלה
ספקי אינטרנט מסונן רבים (כגון נטפרי, Techloq, נטספארק ומשומר) מבצעים סינון תעבורה מוצפנת (SSL Inspection) באמצעות תעודת אבטחה מותקנת במחשב.

היישום כולל **מנגנון מובנה לטעינה אוטומטית של תעודות האבטחה מהמערכת** (`system-ca.js`):
- **Windows**: טוען אוטומטית את כל תעודות השורש ממאגר התעודות של Windows (מאגרי `Cert:\LocalMachine\Root` ו-`CurrentUser`).
- **macOS**: טוען אוטומטית את כל תעודות האבטחה מצרור המפתחות של המערכת (System & Login Keychain).
- **Linux**: מגלה וטוען אוטומטית את חבילות ה-CA של המערכת (`/etc/ssl/certs/ca-certificates.crt` ועוד).
- **הוספת תעודה ידנית בכל פורמט אפשרי (תיקיית `certs/`)**: ניתן להניח תעודות **בכל פורמט** ישירות בתוך תיקיית `certs/` בתיקיית השורש של הפרויקט:
  - ✅ **PEM / Base64** (`.pem`, `.crt`, `.cer`, `.txt`, `.ca-bundle`)
  - ✅ **Binary DER** (`.der`, `.cer`, `.crt`)
  - ✅ **PKCS#7 / CMS Bundles** (`.p7b`, `.p7c`, `.p7s`)
  - ✅ **PKCS#12 / PFX Stores** (`.pfx`, `.p12`)
  - ✅ **מחרוזת Base64 נקייה ללא כותרות**
  - או להגדיר את משתנה הסביבה `NODE_EXTRA_CA_CERTS` / `SSL_CERT_FILE`.

> [!TIP]
> **ללא צורך בהגדרה ידנית**: אם תעודת האבטחה של הסינון (כגון נטפרי או Techloq) כבר מותקנת במחשבכם, התוכנה תזהה אותה אוטומטית בהפעלה. במידה ולא, פשוט הניחו את קובץ התעודה בתיקיית `certs/`.

### 4. 💻 תקשורת מקומית (Localhost / Loopback)
ממשק המשתמש מתקשר עם השרת המקומי באותו מחשב:

| כתובת | פורט | ייעוד |
|---|---|---|
| `http://localhost:3000` (או `127.0.0.1:3000`) | `3000` (או `3001`–`3010`) | תקשורת פנימית בין הדפדפן לשרת Express |

יש לוודא שתוכנת הסינון או חומת האש אינן חוסמות תעבורת רשת מקומית פנימית (`127.0.0.1` / `localhost`).

## 📦 בניית קובצי התקנה (Standalone Binaries)

ניתן לייצא את היישום לחבילות התקנה עצמאיות עבור Windows, macOS או Linux באמצעות `electron-builder`:

```bash
# בנייה עבור Linux (קובצי AppImage ו-deb)
npm run build:linux

# בנייה עבור Windows (מתקין exe וגרסה ניידת Portable)
npm run build:win

# בנייה עבור macOS (קובצי DMG ו-zip)
npm run build:mac
```

הקבצים המוכנים יישמרו בתיקיית `dist/`.

## 📋 רשימת בדיקות מומלצת לערב יום כיפור

לפני כניסת הצום:
1. **הפעלת התוכנה**: פתחו את היישום והעבירו אותו למצב **מסך מלא** (Fullscreen).
2. **הגדרת שפה ומרווחי שיעורים**: היכנסו ל**הגדרות** (⚙️), בחרו את השפה המועדפת, הגדירו את מרווח האכילה ($T$) שנפסק עבורכם, וודאו ששעת מוצאי הצום תואמת את לוח בית הכנסת המקומי שלכם.
3. **חיבור מד סוכר**: במידה ואתם עונדים חיישן FreeStyle Libre, סמנו **הפעל ניטור LibreLinkUp**, בטלו את מצב הדמו והזינו את פרטי חשבון העוקב. לחצו על **בדוק התחברות ל-Libre** כדי לוודא שמופיעה קריאה תקינה.
4. **בדיקת עוצמת שמע**: לחצו על כפתורי הבדיקה **בדוק ערוץ א'**, **בדוק ערוץ ב'** ו**בדוק התראת סוכר** כדי לוודא שעוצמת השמע ופרופיל הצליל נעימים וברורים.
5. **הפעלת הטיימר**: לחצו על כפתור **הפעל טיימר**.
6. **הפעלת מגן הנעילה**: לחצו על כפתור **מגן נעילה** (🛡️) בסרגל העליון. יופיע הבאנר האדום המגן על המסך והמקלדת מכל נגיעה אקראית או מחיות מחמד לאורך כל החג.

המערכת בנויה בארכיטקטורת i18n מודולרית ואוטונומית. כדי להוסיף שפה חדשה (למשל צרפתית, ספרדית, יידיש וכו'):

4. הריצו `node tests/test-i18n.js` לוודא התאמה מלאה של כל המפתחות.
